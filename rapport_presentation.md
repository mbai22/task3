# Rapport de présentation – Tâche 3 : Frontend avec HTML, CSS et JavaScript

## 1. Objectif de la mission

Cette mission consistait à développer une interface web moderne pour une banque vitrine, en mettant en œuvre les bases du développement frontend. L’objectif principal était de concevoir une page responsive capable de récupérer des données depuis une API REST et de les afficher dynamiquement de manière claire et professionnelle.

## 2. Problématique

Le principal enjeu était de créer une interface simple mais crédible, en respectant les bonnes pratiques de conception et en démontrant la communication entre le frontend et une source de données externe. Il fallait également garantir que l’application reste lisible, ergonomique et fonctionnelle sur différents supports.

## 3. Solution mise en place

Nous avons réalisé une page d’accueil pour Chelka Bank avec :

- une section d’introduction forte,
- une présentation des services,
- une partie clients alimentée par l’API,
- un tableau de mouvements financiers,
- un design premium avec palette luxe et micro-animations.

Le front-end a été construit en HTML5, CSS3 et JavaScript, en utilisant la méthode Fetch pour communiquer avec une API publique. Les données récupérées sont ensuite injectées dans la page pour rendre le site dynamique.

## 4. Technologies utilisées

- HTML5 pour la structure du contenu.
- CSS3 pour la mise en page, les couleurs et le responsive design.
- JavaScript pour l’interactivité.
- Fetch API pour la récupération de données.
- Font Awesome pour des icônes professionnelles.

## 5. Résultat obtenu

Le projet aboutit à une interface élégante, moderne et fonctionnelle, adaptée à un contexte bancaire. Il permet de démontrer les compétences nécessaires pour créer une première application frontend connectée à un backend ou à une API.

## 6. Conclusion

Cette tâche valide les compétences fondamentales du développement web front-end : structure HTML, stylisation CSS, logique JavaScript, gestion des données asynchrones et intégration d’une interface crédible pour un projet professionnel. Le rendu est visuellement soigné, fonctionnel et prêt pour une présentation soutenance.
